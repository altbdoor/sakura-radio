# sakura-radio

## Just a personal radio player

Wanted a super simple personal radio player with stations that I liked.

Decided to try building it with [Alpine.js](https://github.com/alpinejs/alpine),
and threw in a [router](https://github.com/shaunlee/alpinejs-router) for good fun.

Using Alpine.js seems okay for simple use cases like this. Though admittedly,
the lack of a router resolver kinda stumped me for a bit.

Radio playback was completely handled by [hls.js](https://github.com/video-dev/hls.js).
CSS styling with [normalize](https://github.com/necolas/normalize.css)
and [sakura](https://github.com/oxalorg/sakura).
